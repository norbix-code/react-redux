# Examples

Each subfolder is a self-contained app demonstrating one or more patterns from `@norbix/react-redux`. To run any of them:

```sh
cd examples/<name>
npm install
npm run dev
```

| Folder | What it shows |
|---|---|
| [`basic/`](./basic) | Provider + store wiring · login mutation · paginated users list with invite/block/delete · running query against a database collection · error display from `SerializedNorbixError` |

More to come — community PRs welcome (Next.js App Router setup, SSR with per-tenant clients, optimistic updates, paginated infinite scroll).
